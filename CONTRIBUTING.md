# Участие в разработке Stream Music Request

Спасибо за интерес к Stream Music Request (SMR)!

## Как предложить изменение

1. Перед крупным изменением откройте Issue и опишите задачу.
2. Для сообщения об ошибке используйте шаблон **Сообщить об ошибке**.
3. Для новой возможности используйте шаблон **Предложить улучшение**.
4. Укажите версию SMR, версию Windows и шаги, позволяющие воспроизвести проблему. Перед отправкой журналов удалите из них токены, личные данные и другую конфиденциальную информацию.

## Изменения кода

Перед подготовкой крупного Pull Request сначала согласуйте подход с автором через Issue. Не добавляйте новые зависимости и не меняйте архитектуру или поведение существующих функций без предварительного обсуждения.

Проверяйте изменения сборкой:

```powershell
dotnet build .\Stream.MusicRequest.slnx -c Release
```

Перед предложением изменений по возможности проверьте затронутые сценарии приложения вручную.

## Условия использования

На текущем этапе у проекта нет отдельной лицензии. Публикация репозитория сама по себе не предоставляет разрешения на свободное повторное использование, распространение или создание производных продуктов. Поэтому до согласования с автором не отправляйте Pull Request, предполагающий включение вашего кода в проект.

## Общение

Пишите по существу, описывайте ожидаемое и фактическое поведение и сохраняйте уважительный тон. Предложения и сообщения об ошибках помогают определить дальнейшее развитие SMR, но их принятие не гарантируется.
