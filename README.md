# Stream Music Request (SMR) — заказ музыки на Twitch через Яндекс Музыку

**Stream Music Request (SMR)** — приложение для Windows, которое помогает стримерам организовать **заказ музыки зрителями на Twitch**, воспроизведение треков из **Яндекс Музыки**, очередь заявок и фоновую музыку во время трансляции.

Зрители могут отправлять музыкальные заявки через награды Twitch Channel Points и DonationAlerts. Стример управляет очередью, приоритетами заказов, воспроизведением с помощью горячих клавиш и отображением текущего трека в OBS. SMR — самостоятельное Windows-приложение для музыкальных заказов на стриме.

**Текущая версия в разработке:** 1.4.1. Последняя опубликованная стабильная версия — 1.4.0. До выпуска 1.4.1 описание и функции могут уточняться.

## Возможности

- **Яндекс Музыка:** авторизация, воспроизведение сохранённого плейлиста или персональной радиостанции «Моя волна».
- **Заказы музыки на Twitch:** приём ссылок на треки и управление очередью музыкальных заявок.
- **Twitch Channel Points:** приём заказов и пропуск трека через награды канала; сообщения в чат об успешных и отклонённых заказах.
- **DonationAlerts:** музыкальные заказы через донаты с настройкой точных сумм для обычного заказа, приоритетного заказа и пропуска трека.
- **Приоритетные заказы:** обработка обычных и SUPER-PRIORITY заказов с учётом очереди.
- **Управление очередью:** блокировка треков и пользователей, управление воспроизведением.
- **Глобальные горячие клавиши (1.4.1):** настройка команд для следующего трека, предыдущего трека и воспроизведения/паузы. Работают, даже когда окно SMR не находится на переднем плане.
- **Ползунки главного окна (1.4.1):** громкость и позицию трека можно менять щелчком или перетаскиванием; изменённая громкость сохраняется автоматически.
- **OBS Studio:** виджет текущего трека с обложкой и несколькими вариантами оформления, а также отдельный аудиопоток.
- **Настройки подключений:** управление Twitch, DonationAlerts, музыкальным источником, аудиоустройством, наградами и поведением приложения.
- **История изменений:** в настройках приложения показывается история из того же файла [CHANGELOG.md](CHANGELOG.md), который находится в репозитории.

Подробные инструкции собраны в [руководстве пользователя](USER_GUIDE.md).

## Кому подойдёт приложение

SMR пригодится Twitch-стримерам, которые хотят принимать заказы песен от зрителей через баллы канала или DonationAlerts, использовать Яндекс Музыку, управлять приоритетом заявок и показывать информацию о текущем треке в OBS. Это приложение для музыкальных заказов на стриме, а не универсальная платформа для управления всеми инструментами канала.

## Требования

- Windows x64 для готовой сборки.
- .NET 10 SDK для сборки из исходного кода.
- Подключение к интернету для авторизации и работы с внешними сервисами.
- Аккаунты Яндекс Музыки, Twitch и/или DonationAlerts — в зависимости от используемых функций.
- OBS Studio — если нужен виджет на трансляции.

## Сборка из исходного кода

1. Установите .NET 10 SDK.
2. Склонируйте репозиторий или скачайте его архив.
3. Откройте терминал в каталоге проекта.
4. Выполните команду:

```powershell
dotnet build .\Stream.MusicRequest.slnx -c Release
```

Для публикации автономной сборки Windows x64 в проекте предусмотрен профиль:

`Stream.MusicRequest.App/Properties/PublishProfiles/win-x64-single-file.pubxml`

Перед использованием на трансляции рекомендуется проверить нужные подключения, горячие клавиши и настройки на своём компьютере.
