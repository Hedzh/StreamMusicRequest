# Stream Music Request (SMR)

**Stream Music Request (SMR)** — приложение для Windows, которое помогает стримерам организовать музыкальные заказы зрителей и управление фоновой музыкой во время трансляции.

Проект разработан Hedzh для русскоязычных стримеров. Сейчас основным музыкальным источником является Яндекс Музыка.

> **Текущий статус:** версия 1.4.0. Проект развивается; возможны ошибки и изменения поведения между версиями.

## Возможности

- **Яндекс Музыка:** авторизация, воспроизведение сохранённого плейлиста или персональной радиостанции «Моя волна».
- **Заказы зрителей:** приём ссылок на треки и управление очередью.
- **Twitch:** музыкальные заказы и пропуск трека через Channel Points, сообщения в чат об успешных и отклонённых заказах.
- **Donation Alerts:** музыкальные заказы через донаты с настройкой сумм для обычного заказа, приоритетного заказа и пропуска трека.
- **Приоритеты воспроизведения:** обработка обычных и SUPER-PRIORITY заказов с учётом очереди.
- **Управление очередью:** блокировка треков и пользователей, управление воспроизведением.
- **OBS:** виджет текущего трека с обложкой и несколькими вариантами оформления.
- **Настройки:** управление подключениями, источником основной музыки, громкостью, наградами Twitch и поведением приложения.

Подробности и инструкции по настройке собраны в [руководстве пользователя](USER_GUIDE.md). История изменений по версиям находится в [CHANGELOG.md](CHANGELOG.md).

## Требования

- Windows.
- .NET 10 SDK для сборки из исходного кода.
- Подключение к интернету для авторизации и работы с внешними сервисами.
- Аккаунты Яндекс Музыки, Twitch и/или Donation Alerts — в зависимости от используемых функций.
- OBS Studio — если нужен виджет на трансляции.

## Сборка из исходного кода

1. Установите .NET 10 SDK.
2. Склонируйте репозиторий или скачайте его архив.
3. Откройте терминал в каталоге проекта.
4. Выполните команду:

```powershell
dotnet build .\Stream.MusicRequest.slnx -c Release
```

Для публикации автономной сборки Windows x64 в проекте предусмотрен профиль:

`Stream.MusicRequest.App/Properties/PublishProfiles/win-x64-single-file.pubxml`

Перед публикацией сборки для использования на трансляции рекомендуется проверить работу нужных подключений и настроек на своём компьютере.
