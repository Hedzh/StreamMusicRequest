# Тест «Моя волна»

Это изолированный proof-of-concept для проверки интеграции Yandex Music «Моя волна» с SMR.

## Что проверяет тест

1. Авторизацию Yandex Music.
2. Получение персональной станции `user:onyourwave`.
3. Получение первой пачки рекомендованных треков.
4. Получение прямой ссылки на аудио.
5. Реальное воспроизведение выбранного трека через существующий NAudio-плеер SMR.
6. Отправку событий `radioStarted`, `trackStarted`, `trackFinished` и `skip`.
7. Получение следующей пачки рекомендаций с продолжением текущей цепочки.

Рабочая архитектура SMR при этом не изменяется.

## Запуск

Из корня репозитория:

```powershell
dotnet run --project .\Tests\YandexMusicMyWaveTest\YandexMusicMyWaveTest.csproj
```

Если переменная окружения `YANDEX_MUSIC_TOKEN` не задана, тест предложит пройти авторизацию через код устройства.

Можно заранее задать OAuth-токен:

```powershell
$env:YANDEX_MUSIC_TOKEN="ВАШ_ТОКЕН"
dotnet run --project .\Tests\YandexMusicMyWaveTest\YandexMusicMyWaveTest.csproj
```

Токен не записывается в файлы проекта.

## Управление

После получения пачки тест показывает список треков.

- Введите номер — начать воспроизведение.
- `Enter` — пропустить текущий трек.
- `Q` — выйти.

После завершения или пропуска тест запрашивает следующую пачку «Моей волны».

## Важно

Тест использует неофициальный API-клиент Yandex Music и Rotor API. Это экспериментальный стенд, а не часть основной архитектуры SMR.

Пока тест не добавляется в основное решение и не изменяет существующие сервисы, настройки или UI.
